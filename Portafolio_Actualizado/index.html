02 Proyecto técnico · Aplicación webTechnical project · Web app

RutinaPro

Entrena con método. Progresa con datos.

Train with method. Progress with data.

Aplicación web para la gestión de entrenamientos físicos, desarrollada de principio a fin en Java con arquitectura MVC: desde la base de datos hasta la última pantalla.

A web application for managing physical training, built end to end in Java with an MVC architecture: from the database to the very last screen.

Vídeo · RutinaProVideo · RutinaPro

Qué esWhat it is

RutinaPro permite a los usuarios registrarse y crear rutinas personalizadas, organizadas en entrenamientos y ejercicios. Su estructura jerárquica facilita organizar el progreso deportivo: crear, editar y eliminar de forma sencilla e intuitiva.

RutinaPro lets users sign up and create personalised routines, organised into workouts and exercises. Its hierarchical structure makes it easy to organise training progress: create, edit and delete in a simple, intuitive way.

Cómo se organizaHow it's organised

  1. 01RutinaRoutine El objetivo y el tipo de entrenamiento.The goal and type of training.
  2. 02EntrenamientoWorkout Cada sesión, con fecha, duración y notas.Each session, with date, duration and notes.
  3. 03EjercicioExercise Repeticiones o duración de cada ejercicio.Reps or duration for each exercise.
  4. 04HistorialHistory Todo queda registrado para medir el progreso.Everything is logged to measure progress.
